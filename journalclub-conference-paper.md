# Journal Club Slides — Conference Paper

For major conferences such as **NeurIPS, ICML, ICLR, AAAI, RSS, ICRA, IROS**, etc.

## Goal
Quickly explain the **problem, technical novelty, method, evidence, limitations, and practical value**.

## Recommended Slides

1. **Paper Overview**
   - Title, authors, affiliations, conference, year
   - Figure 1 / main demo

2. **Problem & Motivation**
   - What problem is being solved?
   - Why do existing methods fail?

3. **Gap → Core Idea**
   - Summarize as:  
     **Existing Approach → Limitation → Proposed Solution**

4. **Method Overview**
   - One architecture / pipeline figure
   - Input → Core Modules → Output

5. **Technical Contributions**
   - Focus only on genuinely new components
   - Explain the key mechanism, not every implementation detail

6. **Experiments**
   - Main benchmarks
   - Strong baselines
   - Real-world / simulation setup when relevant

7. **Key Results**
   - Main quantitative result
   - Ablations
   - Generalization / robustness / efficiency

8. **Critical Discussion**
   - Is the novelty substantial?
   - Do experiments support the claims?
   - Hidden assumptions / missing baselines / failure cases

9. **Connection to Our Research**
   - What can we reuse, modify, or challenge?

10. **Take-Home Messages**
    - 2–3 key messages
    - 2–3 discussion questions

## Slide Style

- **One slide, one message**
- Start from the **system overview**, then zoom into details
- Use **videos, diagrams, tables, and trajectories** whenever possible
- Prefer **message-style titles**
- Avoid long related-work or implementation slides

## Suggested Length

**15–25 min / 12–18 slides**

> Understand the core idea and evidence first; implementation details can be discussed later.
